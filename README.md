# Mealie Helm chart
Mealie is a self hosted recipe manager, meal planner and shopping list. For more information visit the upstream project.

## Forked Repository
This is a personal fork of https://github.com/jvalskis/mealie-helm and no assurances are given for this chart.
I did use AI to work on this, no I will not fix issues unless it impacts me.

## Mealie project
https://github.com/mealie-recipes/mealie

## Installing the chart
```console
helm repo add mealie https://schnabel45.github.io/mealie-helm/
helm repo update
helm install mealie mealie/mealie
```
